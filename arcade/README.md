# 片场街机

电影语言的纯游戏站（独立于主站，主站文件一概不改）。

| 玩法 | 内容 |
| --- | --- |
| **对片** | 把「手法名」和「片例」配对，限时连消。课程线 12 关（对应 12 章）+ 图鉴线 31 包（按原站 13 个分类切包，覆盖全部 424 条手法）+ 无尽模式 + 每日片单（全站同款、连续天数奖励） |
| **导演椅** | 24 个镜头任务：在取景器里亲手拍出荷兰角、推 / 拉、摇、甩、焦点转移、手持、跟拍、希区柯克变焦、急推等 |
| **灯光台** | 26 个布光 / 调色任务：椭球半身像 + 逐像素 Lambert 打光，摆灯位、调硬度 / 色温 / 补光 / 轮廓光 / 饱和度，打出逆光、伦勃朗光、黄金时刻、黑色电影等 |
| **片库图鉴** | 424 张收集卡：游戏里遇到的手法自动收进来，一次配对成功算「认熟」 |
| **成就** | 34 个，含 13 个分类大师 |

答得越好，舞台越热闹：胶片边 → 颗粒 → 镜头光 → 首映灯光，配乐逐层加入（Web Audio 合成，无音频文件）。答错不扣分、不结束。

## 文件

`index.html` · `style.css` · `audio.js`（音效与 BGM）· `core.js`（数据 / 存档 / 路由 / 舞台）· `match.js` · `dir.js` · `lab.js` · `album.js`（图鉴 + 成就）· `main.js`（大厅与启动）· `data.js`（生成物）。

数据来自主站的 `data-tutorial.js` 与 `build/library.json`，重新生成：`python3 arcade/build_data.py`。
本地运行：`python3 -m http.server -d arcade 8000`。存档在 localStorage（`arc-save`）。
部署：在 `arcade/` 目录下 `vercel deploy --prod`（独立项目 `cinematic-arcade`，主站 `.vercelignore` 已排除 `arcade`）。
片例与定义取自 Melies，版权归原站所有。
