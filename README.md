# 电影语言入门｜从看懂到拍出来

面向零基础的电影语言学习站：12 章 48 课手机练习 + Melies「Cinematic techniques」全部 424 条手法图鉴（真实片例、中英定义、可复制的提示词），附看片测验与提示词收藏夹。

线上：https://cinematic-tutorial.vercel.app

- 纯静态站点：`index.html` + `data-tutorial.js` + `data-library.js`（均为生成物）。
- 源文件与数据管线在 `build/`：改 UI 编辑 `build/page.html`、`build/app.css`、`build/app.js`，然后运行 `python3 build/generate.py`。
- 数据模型、实现约定与验证记录见 [HANDOFF.md](HANDOFF.md)。

片例、定义与英文原文取自 [Melies](https://melies.co/cinematic-techniques)，版权归原站所有；中文为学习用对照翻译。
